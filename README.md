# Claudeセットアップガイド

画像を含むサイト一式です。追加のインストールやビルドは不要です。

## アップロード

1. ZIPを展開します。
2. 中のindex.html、style.css、guide.js、assetsフォルダを、同じ階層のままGitHubのリポジトリへアップロードします。
3. ZIP自体をアップロードしてもWebページとしては表示されません。必ず展開した中身を使ってください。

index.htmlをリポジトリの一番上に置き、assetsフォルダの名前や中身を変更しないでください。

## 自分のPCで確認

index.htmlをダブルクリックすると開けます。ローカル表示ではブラウザの制限によりコピー機能が文字選択に切り替わる場合があります。

## 内容

Mac・Windows切替、日本語のお願い文9種類、実画面と操作イメージ、サービス連携、用語集、手動セットアップの補足を含みます。
