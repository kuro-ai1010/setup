難しい準備は、
Claudeにお願いしよう。

最初にアプリを開いたら、あとは日本語で。
コピーできるお願い文で、準備から最初の制作まで進めます。

選んだOSに合わせて、このページの手順とコマンドが切り替わります。

1アプリを開く→2お願いを送る→3動くか確認
自分でやるのは、最初と確認

開く・選ぶ・許可する

アプリを入れてログイン。作業するフォルダを選んだら、Claudeにバトンタッチします。

準備は、会話で進める

調べる・整える・試す

必要な道具の確認や設定は、Claudeが実行できる範囲で担当。自分の操作が必要なときだけ案内してもらいます。

使うのは、Claudeアプリの「Code」の会話欄です。ここならPC上の作業を頼めます。ふだんの相談用チャットだけで、PCへの設定まで自動で済むわけではありません。

先に用意するのは、これだけ

  • Windowsとインターネット
  • Claudeアプリと、ログインするアカウント
  • Codeが使える契約（Pro / Max / Team / Enterpriseなど）
GitやNode.jsを、先に全部そろえなくても大丈夫。まずアプリのCodeを開き、やりたいことを伝えます。必要な道具の確認や追加作業は、Claudeに頼みましょう。

対応プランやPCの条件は公式ダウンロード ↗と公式の始め方 ↗で確認できます。

CHAPTER 01

最初の操作だけ、自分で

アプリを入れる → ログイン → Codeで練習場所を選ぶ。

1

Windows用のClaudeアプリを入れる

ここは自分で操作します

公式ダウンロードページ ↗を開き、「Desktop」の欄を探します。

  1. 通常は「Windows」のDownloadを押します。ARMのPCなら「Windows (arm 64)」を選びます。
  2. エクスプローラーの「ダウンロード」で、保存されたClaudeのセットアップファイルをダブルクリックします。
  3. 画面にインストールのボタンが出たら押し、完了を待ちます。
  4. スタートメニューで「Claude」を検索して開きます。

インストール＝ PCにアプリを入れて、使える状態にすること。スマホにアプリを入れるのと同じ感覚です。

通常のWindowsか、ARMか分からないとき

スタート → 設定 → システム → バージョン情報の「システムの種類」を見ます。x64なら通常のWindows版、ARMならarm 64版を選びます。

✓ 次へ進める目印Claudeアプリが開いたらOKです。
2

ログインして「Code」を開く

Claudeアプリの中で操作します
  1. Claudeにログインします。契約がある人は、その契約と同じアカウントを使います。
  2. 「Code」と書かれたタブ・入口を押します。通常の相談用チャットとは入口が違います。
  3. 「Local」を選びます。これは「このPCで作業する」という意味です。
  4. 「Select folder」を押し、練習用の空フォルダを選びます。まだなければ、次の説明を見て作ってください。

Code＝ Claudeにファイル作りやPC上の作業を頼める場所。プログラミング経験がなくても、日本語でお願いできます。

フォルダ＝ ファイルを入れる箱。まずは練習用の箱を1つ用意します。

練習用フォルダの作り方
  1. WindowsキーとRを押し、%USERPROFILE% と入力してEnterを押します。これは自分専用のフォルダを開くための住所です。
  2. 開いたエクスプローラーで、何もない場所を右クリック →「新規作成」→「フォルダー」を選びます。
  3. 名前を claude-practice にして、ClaudeのSelect folderでそのフォルダを選びます。
Codeに進むところで「Gitが必要」と表示されたら、まずアプリを更新して開き直します。まだ進めない場合は、このページ下部の「自分で設定する方法」のGitの手順を使ってください。開始前の作業を、まだ開けないCodeに任せることはできません。
✓ 次へ進める目印Codeの会話欄が開き、作業するフォルダが選ばれています。

CHAPTER 補足 A

WindowsにGitを入れる

Gitは「制作のセーブ履歴」を残す道具です。

Gitは「制作のセーブ履歴」を残す道具です。GitHubというWebサービスとは別物。インストールだけならGitHubへの登録は不要です。

1

PowerShellを開き、Gitがあるか確かめる

Windows標準のPowerShell
  1. Windowsキーを押し、検索欄に「PowerShell」と入力します。
  2. 「Windows PowerShell」を通常の「開く」で起動します。Claude Codeのために「管理者として実行」は必要ありません。
  3. 入力行の先頭に PS C:\Users\…> とあることを確認します。下のコマンドを貼り付け、Enterを押します。
PowerShellに貼り付け → Enter
git --version
git version 2.xx.x のような表示が出たら、Gitは入っています。次のインストール手順を飛ばし、03へ進んで構いません。表示される番号はその時の版で異なります。
✓ 次へ進める目印Gitが入っているか、追加が必要か判断できました。
2

Git for Windowsを公式から入れる

ブラウザ → Git公式 → セットアップ

Git公式のWindows用ページ ↗を開きます。

  1. 「Git for Windows/x64 Setup」をクリックします。ARMのPCなら「ARM64 Setup」を選びます。
  2. ダウンロードしたGitの .exe を開きます。Windowsの確認では、公式から入手したGitであることを確認して進めます。
  3. ライセンス表示と保存先を確認します。通常は既定のまま「Next」で進めます。
  4. エディター選択の画面も、特に指定がなければ既定のまま進められます。
  5. 「Adjusting your PATH environment」では、推奨の「Git from the command line and also from 3rd-party software」が選ばれていることを確認します。
  6. 残りも通常は既定のまま「Next」→「Install」→「Finish」と進めます。
  7. 開いていたPowerShellを閉じ、スタートから新しく開きます。git --version を実行します。

Gitの名前・メール設定は今すぐ必要？

インストールやClaudeの初回起動だけなら不要です。後で変更履歴を「コミット」として保存するときに使います。以下は入力例なので、自分の情報に置き換えてください。

1

PowerShell・1行ずつ実行

現在の場所は Get-Location で確認できます。claude-practice で終わる場所になっていればOKです。

PowerShell → ブラウザ → PowerShell

名称役割どこで設定？

プラグインSkillや連携機能などをまとめた追加セットCodeアプリの「＋」→「Plugins」、またはCLIの /plugin

Claudeアプリ・ブラウザからサービスをつなぐ

チャットの「＋」→ Connectors → Manage connectors

例としてNotionを接続します。連携したいサービス側のアカウントも用意しておきます。

  1. Claudeのチャット入力欄の左下にある「＋」をクリックします。
  2. 「Connectors（コネクタ）」→「Manage connectors（管理）」を開き、コネクタ見出し横の「＋」を押します。「Customize → Connectors」から開く方法もあります。

Claude Codeに公式プラグインを追加する

MCPでNotionに直接つなぐ

プラグインを使わず、CLIに接続先を追加する方法

Notionのプラグインですでにつながっている場合は、この手順を飛ばします。ここでは練習プロジェクト内で使える接続を1つ作ります。

  1. Claude Code内なら /exit で終了し、PCのターミナルに戻ります。
  2. 練習フォルダ claude-practice にいることを確かめます。
  3. 以下を実行して、公式ドキュメントに記載されたNotionの接続先を登録します。
PowerShellで実行
claude mcp add --transport http notion https://mcp.notion.com/mcp

次に claude で起動し、Claude Code内で次を実行します。

Claude Code内で入力
/mcp
  1. 一覧から「notion」を選び、認証が必要な場合はログイン／Authenticateの案内を選びます。
  2. 開いたブラウザでNotionにログインします。アクセス先や許可する権限を確認して進めます。
  3. ターミナルに戻り、/mcp で接続状態と利用できるツールを確認します。
  4. 「Notionの『練習メモ』ページを探して要約して。変更はしないで」のように、実在する自分のページ名で読み取りを試します。
このHTTPSのリモート接続例では、MCP用にNode.jsやPythonを自分のPCへ追加する必要はありません。npx や uvx で動くローカルMCPサーバーとは必要な準備が違います。
接続を確認・削除するには
PCのターミナルで状態・設定を確認
claude mcp list
claude mcp get notion

このガイドで登録した接続を削除する場合：

PCのターミナルで実行
claude mcp remove notion

これはClaude Code側の登録削除です。サービス側に与えた権限も取り消す場合は、Notionなど接続先の設定で連携アプリの許可を解除します。

CHAPTER 補足 E

エラー別の対処

表示されたエラーが分かる人向けです。

エラー文を見て、当てはまる項目を開いてください。コマンドは「どこへ入力するか」を先に確認します。

claude が見つからない／認識されない

まずPowerShellをすべて閉じ、新しく開いて claude --version を試します。それでも出ない場合は、インストール時の「Setup notes」に従います。

PowerShellで、インストール先が存在するか確認します。

PowerShellで実行
Test-Path "$env:USERPROFILE\.local\bin\claude.exe"

Trueなら、ユーザーのPATHへ追加します。以下は今あるPATHを残して追記する設定です。実行後はPowerShellを閉じ、新しく開いてください。

PowerShellで実行
$claudeGuidePath = [Environment]::GetEnvironmentVariable("PATH", "User")
[Environment]::SetEnvironmentVariable("PATH", "$claudeGuidePath;$env:USERPROFILE\.local\bin", "User")

FalseならPATHだけの問題ではありません。03のインストール結果を確認します。

出典：公式のPATH対処方法 ↗

irm が認識されない／「&&」のエラーが出る

PowerShellとCMDのコマンドを混ぜている可能性があります。Windowsのスタートで「PowerShell」を検索し、先頭が PS の画面を開いてから、Windows用コマンドを実行してください。Claudeのチャット欄にインストールコマンドを貼ってもインストールにはなりません。

Windowsで32-bitやx86のエラーが出る

「Windows PowerShell (x86)」を開いていたら閉じ、(x86)の付いていない「Windows PowerShell」を開きます。PC自体が32bitの場合はClaude Codeの対応条件を満たしません。設定→システム→バージョン情報でシステムの種類を確認します。

Git Bashが見つからないと言われる

WindowsでGitをインストールした後、PowerShellを開き直します。通常の場所にインストールした場合、以下でファイルの存在を確認します。

PowerShellで実行
Test-Path "C:\Program Files\Git\bin\bash.exe"

Trueの場合だけ、次を実行してからClaudeを起動します。この設定は現在のPowerShellウィンドウ内だけ有効です。

PowerShellで実行
$env:CLAUDE_CODE_GIT_BASH_PATH="C:\Program Files\Git\bin\bash.exe"
claude

Falseの場合はインストールした場所を確認し、実際にあるbash.exeのパスを使います。最新の公式ではGitなしのPowerShell動作も案内されています。

ログイン済みなのにCodeを使えない

契約しているアカウントとログイン先が同じか確認します。無料チャットへのログインだけではCodeの利用条件を満たしません。CLIなら /login、アプリならログインし直して再起動します。組織の管理設定や利用上限が原因の場合もあります。

APIキーを自分で設定していた人は、月額プランではなくAPI認証を優先していないかも公式の認証ガイドで確認してください。

出典：アカウントと認証 ↗

インストールが進まない／403・証明書のエラー

通信状態、対応OS、端末の管理制限を確認します。会社のネットワークなら管理者にエラー文を伝えます。HTMLの文字列が流れた場合、インストーラーではなくエラーページが返った可能性があります。

証明書の検証やセキュリティ機能を無効にして進めず、エラー文に対応する公式手順を確認してください。

出典：インストールとログインのトラブル解決 ↗

プラグインは入ったのにサービスを読めない

CLIなら /mcp で接続状態を確認します。「要認証」ならログイン、「failed」なら詳細を読みます。プラグインのインストールと、外部サービスの認証は別工程です。

指定ページが自分のアカウントから見えるか、別のワークスペースに接続していないかも確認します。アプリでは対象コネクタが会話で有効か確認してください。

Node.jsを入れるよう言われた

Claude Code本体のネイティブ導入には不要です。一方、作成中のJavaScriptアプリや、npx で起動するMCPには必要な場合があります。そのツールが指定する対応版を公式サイトから入れます。用途を確認してから追加しましょう。

更新はどうする？

このガイドのネイティブインストールは自動更新に対応しています。手動で確認・更新する場合はClaude Codeを終了し、ターミナルで次を実行します。

PCのターミナルで実行
claude update
claude --version

HomebrewやWinGetで入れた場合は、そのパッケージ管理の更新コマンドを使います。インストール方式を混ぜないようにします。

ここまでできたら、準備完了。

  • Claudeにログインできた
  • 選んだ方法でCodeを起動できた
  • 練習用フォルダでファイルを作れた
  • 必要なサービスを接続し、読み取りを試せた

次は「作りたいもの」を、小さく1つ頼んでみましょう。
